Algoritmos com Blocos

Vamos usar blocos de comando para montar um algoritmo. Editaremos um programa para Troco, assim entendemos como o computador executa cada instrução.

📚 Conceitos

Do Papel para o Computador

Um PROGRAMA é uma sequência de comandos que o computador executa. Cada tipo de comando tem uma função diferente.

🧩 Os quatro tipos de comando
🚩

Eventos

Definem quando o programa começa. Ex: "ao clicar no botão Iniciar". São sempre os primeiros blocos.

❓

Entrada

São os mecanismos que permitem ao programa receber dados do meio externo (periféricos ou sensores) para dentro do fluxo do algoritmo

📦

Variáveis

Uma variável é um espaço alocado no computador destinado a armazenar um dado que pode ser modificado ou consultado a qualquer momento durante a execução do algoritmo.

🖥️

Saída / Resultado

Exibe os resultados para o usuário. Pode mostrar texto, número ou uma mensagem completa, através dos dispositivos de saída (tela, caixas de som, motores).

💡 A lógica do nosso programa

O Robô do Troco vai executar exatamente esta sequência:

🚩 Evento O usuário clica em "Iniciar"
❓ Entrada Pergunta: "Qual o valor do produto?"
📦 Variável Guarda a resposta em preco_produto
❓ Entrada Pergunta: "Qual o valor pago?"
📦 Variável Guarda a resposta em valor_pago
🖥️ Resultado Exibe: "Troco = valor_pago − preco_produto"

🔍 O que cada bloco faz
🚩 Iniciar
Ponto de partida. O programa só começa a executar a partir deste bloco. Sem ele, nada acontece.
❓ Pergunte e aguarde
Coletor de dados. Exibe uma pergunta ao usuário e o programa fica parado até receber a resposta. A resposta fica disponível para ser guardada.
📦 Guarde em [var]
Armazenador. Pega o valor recebido e coloca dentro da variável indicada. É aqui que a "caixinha" recebe o conteúdo!
🖥️ Mostre resultado
Saída. Exibe o resultado calculado usando os valores guardados nas variáveis. O cálculo acontece na hora da exibição.
